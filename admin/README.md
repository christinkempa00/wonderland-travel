# Wonderland Travel — Admin Panel

React + Vite + TypeScript + Tailwind frontend for the admin panel (auth, CMS, reservasi, invoice).

This app talks to the API in [`../server`](../server). For setup, environment variables, and **cara login**, see the [root README](../README.md).

Quick start (requires `server` running on port 4000 first):

```bash
npm install
npm run dev
```

Opens on http://localhost:5173 — you'll be redirected to `/login` automatically if you're not signed in.
